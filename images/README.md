# Gallery photos

1. Add your photo files here (e.g. `img1.jpg`, `court3-final.jpg`). Keep filenames simple — no spaces (use `-` or `_` instead).
2. Open `images.json` (in the folder above this one) and list each filename with the `images/` prefix, e.g.:
   ```json
   [
     "images/img1.jpg",
     "images/court3-final.jpg"
   ]
   ```
3. Commit and push both the photos and the updated `images.json`. The Gallery page reads this file automatically — no code changes needed.

Tip: resize/compress photos before uploading (under ~500KB each) so the gallery page loads quickly, especially on mobile.
