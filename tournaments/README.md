# Tournament snapshots go here

Each monthly tournament is one file, uploaded via the tool's **"Download shareable HTML"** button.

Suggested naming: `YYYY-MM.html`, e.g. `2026-08.html`, `2026-09.html`.

After uploading a new file:
1. Open `index.html` in the repo root.
2. Add one line inside the `<ul>` list, e.g.:
   ```html
   <li><a href="tournaments/2026-09.html">September 2026</a></li>
   ```
3. Commit. GitHub Pages rebuilds automatically within about a minute.
